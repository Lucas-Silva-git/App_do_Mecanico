O App se trata de um auxílio para mecânicos controlarem suas ordens de serviço, fiz primariamente pensando no meu tio que tem sua oficina mas não é muito familiar
com computadores, pensei que sendo no celular talvez ele conseguisse usar, mas pretendo fazer melhorias e talvez lancar na google play algum dia ou disponibilize
o apk para mecânicos de minha região

O app é bem direto ao ponto:
O usuário adiciona uma ordem de servico onde ele Cadastra:
- Nome
- Modelo do Carro
- Placa do Carro
- Problema Apresentado pelo cliente
- Seleciona o status do conserto
- Há também uma barra de pesquisa para que o usuário identifique as ordens de serviço conforme elas forem aumentando
